GCIM unified publication template

Canonical page:
  publication.html

Runtime URL:
  publication.html?id=<publication-id>&lang=<language>

One publication record:
  date
  category
  translations.en
  translations.ar
  translations.es
  translations.zh
  translations.ru
  translations.fr
  translations.uk

Each translation contains:
  title
  categoryLabel
  body[]
  serviceInfo[]
  links[]
  attachments[]

Page order:
  date -> category -> title -> full official text -> service information -> links/attachments

The same publication.html template renders every language version.
The selected language is preserved through gcimPreferredLanguage and ?lang=.
