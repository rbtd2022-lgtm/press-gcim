GCIM Press Office static publication workflow

Authoritative records: content/news.json

Public URLs: <publication-id>-<language>.html, with language one of
  en, ar, es, zh, ru, fr, uk.

Each approved record has date, category and seven translations. Each
translation may contain title, categoryLabel, body[], serviceInfo[], links[]
and attachments[]. body[] may be empty if that is the approved source.

Generation:
  python tools/generate_static_publications.py .

The generator uses publication.html if present; otherwise it uses an existing
English static publication as the layout template. It regenerates seven HTML
pages per record and rebuilds sitemap.xml from all indexable static HTML pages.
Check output against approved records before publishing. Do not invent missing
publication text or silently change existing IDs/URLs.
